# Vision de producto

El sistema futuro debe ayudar al taller a seguir el recorrido principal:

```text
Cliente -> Moto -> Servicio -> Mantenimiento -> Alerta -> Contacto
```

La aplicacion debera permitir gestionar:

- clientes;
- motos;
- historial de servicios;
- mantenimientos;
- intervalos configurables;
- kilometraje;
- alertas proximas;
- alertas vencidas;
- busqueda por patente, nombre o telefono;
- contacto por WhatsApp mediante enlaces `wa.me`;
- estado de contacto;
- observaciones mecanicas;
- exportacion CSV y Excel;
- instalacion como PWA.

La prioridad del producto es que una persona del taller pueda entender el estado del trabajo en pocos segundos.
